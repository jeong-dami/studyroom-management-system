# 스터디룸 예약 관리 시스템

콘솔에서 스터디룸 예약을 등록·조회·수정·삭제할 수 있는 Java 프로그램입니다.
예약 날짜와 이용 시간, 수용 인원, 방 분류를 검사하며 같은 방의 예약 시간이 겹치지 않도록 관리합니다.

## 프로젝트 개요

- 프로젝트명: `studyroom-management-system`
- 개발 언어: Java
- 빌드 도구: Gradle
- 데이터 저장 방식: `ArrayList`를 이용한 메모리 저장
- 실행 클래스: `com.ohgiraffers.studyroommanagementsystem.Application`

데이터베이스나 파일을 사용하지 않으므로 프로그램을 종료하면 실행 중에 등록·수정한 내용은 사라집니다. 프로그램을 다시 실행하면 Repository에 작성된 초기 예약 데이터로 시작합니다.

## 주요 기능

### 1. 예약 등록

예약자명, 스터디룸 분류, 방 이름, 예약 날짜, 시작·종료 시간, 이용 인원을 입력하여 새로운 예약을 등록합니다. 등록이 완료되면 Repository가 예약 번호를 자동으로 부여합니다.

### 2. 예약 조회

- 전체 예약 조회
- 예약 번호로 상세 조회
- 예약자명 또는 스터디룸명으로 검색

검색은 대소문자를 구분하지 않으며 입력한 검색어가 예약자명이나 방 이름에 포함된 예약을 모두 보여줍니다.

### 3. 예약 정보 수정

예약 번호로 기존 예약을 찾은 뒤 예약자명, 분류, 방 이름, 날짜, 시간, 이용 인원을 새로운 값으로 변경합니다. 수정할 때는 해당 예약 자체를 제외하고 다른 예약과 시간이 겹치는지 검사합니다.

### 4. 예약 삭제

예약 번호로 예약을 확인한 뒤 사용자에게 삭제 여부를 한 번 더 묻습니다. `y` 또는 `Y`를 입력한 경우에만 예약을 삭제합니다.

### 5. 잘못된 입력 처리

- 숫자 입력란에 문자를 입력해도 프로그램이 종료되지 않고 다시 입력받습니다.
- 빈 문자열은 허용하지 않습니다.
- 날짜 형식이 잘못되면 `yyyy-MM-dd` 형식으로 다시 입력하도록 안내합니다.
- 존재하지 않는 예약 번호나 스터디룸을 입력하면 오류 메시지를 출력합니다.

## 예약 규칙

예약을 등록하거나 수정할 때 다음 조건을 검사합니다.

1. 실제로 존재하는 스터디룸이어야 합니다.
2. 방 이름의 접두사와 선택한 분류가 일치해야 합니다.
3. 지난 날짜에는 예약할 수 없습니다.
4. 시작 시간은 0시부터 23시 사이여야 합니다.
5. 종료 시간은 1시부터 24시 사이여야 합니다.
6. 종료 시간은 시작 시간보다 늦어야 합니다.
7. 이용 인원은 선택한 방 분류의 수용 범위 안에 있어야 합니다.
8. 같은 날짜와 같은 방에 시간이 겹치는 예약을 등록할 수 없습니다.

시간 중복은 다음 조건으로 판단합니다.

```text
startHour < existingEndHour && endHour > existingStartHour
```

## 스터디룸 분류

| 분류 | enum 상수 | 방 이름 | 수용 인원 | 방 개수 |
|---|---|---|---:|---:|
| 1인실 | `SINGLE` | `S01` ~ `S20` | 1명 | 20개 |
| 2~4인실 | `SMALL` | `A01` ~ `A05` | 2~4명 | 5개 |
| 5~8인실 | `MEDIUM` | `B01` ~ `B03` | 5~8명 | 3개 |
| 9~12인실 | `LARGE` | `C01` ~ `C02` | 9~12명 | 2개 |

방 이름은 사용자가 소문자로 입력해도 대문자로 변환하여 처리합니다.

## 메뉴 구성

```text
===== 스터디룸 예약 관리 시스템 =====
1. 예약 등록
2. 예약 조회
3. 예약 정보 수정
4. 예약 삭제
9. 프로그램 종료
```

예약 조회 메뉴는 다음과 같이 구성되어 있습니다.

```text
---------- 예약 조회 ----------
1. 전체 예약 조회
2. 예약 번호로 조회
3. 예약자명 / 스터디룸명으로 검색
9. 이전 메뉴로
```

## 클래스별 역할

| 클래스 | 역할                                                                |
|---|---------------------------------------------------------------------|
| `Application` | 프로그램 실행, 객체 생성 및 연결, 메인·조회 메뉴 흐름 제어          |
| `StudyroomView` | 콘솔 메뉴와 예약 정보 출력, 사용자 입력 및 입력 형식 예외 처리      |
| `StudyroomController` | 입력값과 예약 규칙 검증, Repository와 View 사이의 작업 조정         |
| `StudyroomRepository` | 스터디룸·예약 목록 보관, 예약 저장·조회·검색·삭제 및 시간 중복 검사 |
| `Studyroom` | 예약 번호, 예약자명, 방, 날짜, 시간, 이용 인원을 담는 모델 클래스   |
| `Category` | 스터디룸 분류별 설명, 수용 인원 범위, 방 개수를 관리하는 enum       |

각 클래스는 역할을 나누어 구성했습니다. View는 입출력, Controller는 업무 규칙 검증, Repository는 데이터 관리, Model은 예약 데이터 표현을 담당합니다.

## 사용된 주요 Java 기능

- 클래스와 객체를 이용한 역할 분리
- `enum`을 이용한 스터디룸 분류 관리
- `ArrayList`를 이용한 예약 및 방 목록 관리
- Stream API의 `filter`, `findFirst`, `anyMatch`, `collect` 활용
- 컬렉션의 `removeIf`를 이용한 예약 삭제 처리
- `LocalDate`를 이용한 예약 날짜 처리
- `try-catch`를 이용한 숫자 및 날짜 입력 예외 처리
- 람다식과 메서드 참조를 이용한 목록 처리

## 실행 방법

### IDE에서 실행

프로젝트를 Gradle 프로젝트로 연 뒤 `Application.java`의 `main()` 메서드를 실행합니다.

### Windows 터미널에서 실행

프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
.\gradlew.bat classes
java -cp build\classes\java\main com.ohgiraffers.studyroommanagementsystem.Application
```

## 초기 데이터

프로그램 실행 시 기능을 바로 확인할 수 있도록 여러 분류와 날짜의 예시 예약 11건이 자동으로 등록됩니다. 날짜는 실행일을 기준으로 내일, 모레, 3일 뒤의 상대 날짜를 사용하므로 시간이 지나도 과거 예약이 되지 않습니다.
